## Description

Before running this project make sure that you have a docker run in you machine.

## Project setup

```bash
$ npm install
```

## Compile and run the project

```bash
# run docker compose
$ docker compose up -d
```

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Run tests

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```
